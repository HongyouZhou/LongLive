# Two-Stream On-Policy Cover Objective

## 1. Motivation

The residual-bucket reward experiment showed that changing only the rollout
scalar is insufficient.  The next objective makes the mode-covering branch
explicit instead of relying on a local anchor term inside the reference update.

This follows the rCM lesson at a lightweight per-reference scale:

```text
reference stream: on-policy, reward-tilted, reference-seeking update
cover stream: LongLive teacher-sampled velocity matching for mode coverage
```

It is not exact forward KL.  It is a reference-tilted mirror-descent surrogate
with a separate LongLive cover branch.

## 2. Loss

The total objective is implemented as alternating inner-loop streams:

```text
L_total = L_reference_on_policy or L_mode_cover
```

The reference stream uses student on-policy rollouts:

```text
x0_s ~ p_student
w_i = EM_weight(r_ref(x0_s))
m_i,f = residual-bucket time weight
raw_shift = (eps - x0_s) - v_student
target = v_LongLive + shift_coef * m_i,f * P_motion(raw_shift)

L_reference_on_policy =
  w_i * ||v_student - sg(target)||^2
  + local_anchor_beta * ||v_student - sg(v_LongLive)||^2
  + lambda_static * L_static
```

The cover stream uses LongLive/anchor rollouts on train/eval prompts:

```text
x0_T ~ p_LongLive(prompt)
x_t = add_noise(x0_T, eps, t)

L_mode_cover =
  cover_loss_weight * ||v_student(x_t, prompt) - sg(v_LongLive(x_t, prompt))||^2
  + lambda_static * L_static
```

The important distinction from the older local anchor is:

```text
local anchor: student-visited points
mode cover:  teacher-visited points
```

## 3. Config

First sentinel config:

```text
configs/per_reference_mp_em_ram_2video_two_stream_on_policy_cover.yaml
```

Key switches:

```yaml
mstep_objective: two_stream_on_policy_cover
reward_motion_mode: residual_bucket
time_weight_mode: residual_bucket_direction

cover_prompt_source: train_and_eval_prompts
cover_step_ratio: 0.25
cover_rollouts_per_outer: 1
cover_loss_weight: 1.0
local_anchor_beta: 0.03
```

The first experiment keeps the same two sentinel units:

- `ucf_Golf-Swing_r00`
- `loveu_miami-surf`

The intended readout is whether explicit teacher-sampled mode coverage prevents
the LOVEU degradation seen with scalar residual-bucket reward while preserving
the UCF improvement over earlier MP-EM-RAM variants.
