## 2. 物理设计

### 2.1 Prediction parameterization(B1):close-form ε 反解

Wan flow matching ↔ paper ε-MSE 的对接靠一行反解,**不需要改 wrapper**。

| 项 | Wan flow scheduler 字面 |
|---|---|
| 加噪 | `x_t = (1 − σ_t) · x_0 + σ_t · ε` |
| 模型原生输出 | `flow_pred = ε − x_0`(`FlowMatchScheduler.training_target`) |
| 互转 | `x_0 = x_t − σ_t · flow_pred` / `flow_pred = (x_t − x_0) / σ_t` |
| **ε 反解** | **`ε = flow_pred + x_0`** |

`WanDiffusionWrapper.forward()` 已经返回 `(flow_pred, pred_x0)`(`wan_wrapper.py:440`),Phase 2 训练步直接:

```python
flow_pred, pred_x0 = teacher_with_lora(noisy_latent, cond_dict, t)
eps_pred = flow_pred + pred_x0   # close-form,no grad surgery
```

Phase 3 时 DMD `_, pred_real_image_cond = self.real_score(...)` 透明 — LoRA 通过 `flow_pred` 影响了 `pred_x0`(close-form 关系),DMD 拿 `pred_x0` 直接用,**不知道也不需要知道 Phase 2 在 ε 上训过**。

**Gradient weighting 副作用**:`ε_pred = x_t + (1 − σ_t) · flow_pred`,所以

```
dL_MSE / dθ = 2 · (ε_pred − ε_gt) · (1 − σ_t) · d flow_pred / dθ
```

低 t(σ → 0)梯度最大,高 t(σ → 1)梯度趋零。物理上跟 motion 信息在 low-noise regime 更可读契合,**第一版不额外加 importance weighting**;若 Phase 3 看到高 t LoRA 行为退化到 base Wan,再考虑 loss weighting(见 §7 Risks)。

### 2.2 Loss(P1):paper 字面 `L_temporal_MSE + L_AD`

```python
# L_temporal_MSE
loss_mse = F.mse_loss(eps_pred, eps_gt)   # eps_gt = 加噪步采样的 noise tensor

# L_AD (appearance-debias,paper α=√2, β=1)
ran_idx = torch.randint(0, F, (1,)).item()
alpha, beta = math.sqrt(2.0), 1.0
eps_pred_dec = alpha * eps_pred - beta * eps_pred[:, ran_idx:ran_idx+1]
eps_gt_dec   = alpha * eps_gt   - beta * eps_gt[:,   ran_idx:ran_idx+1]
loss_ad = F.mse_loss(eps_pred_dec, eps_gt_dec)

loss = loss_mse + loss_ad   # paper 字面等权
```

丢 paper 第三项 `L_spatial`(spatial LoRA 已因 Wan DiT joint 3D self-attn 无 Transformer2D / Temporal 二分被弃)。`α/β` 字面用 paper 值是合法的,因为 B1 选定 → LoRA 在 ε 空间训,paper 物理含义保持(共享 noise = 共享外观,anchor-frame 减法消之)。

### 2.3 Timestep 分布(C1):continuous uniform

```python
t = torch.randint(20, 980, (batch_size,))   # 对齐 DMD `_compute_kl_grad` 调用范围
```

paper 字面是 30-step DDIM 离散 t 点,**不照搬** — Phase 3 DMD 在 `t ∈ [min_step=20, max_step=980]` 连续段调 real_score(`dmd.py:42-43`),LoRA 要在整段被训到,否则 DMD 调用时落在 LoRA 没见过的 t 上 → score 不可靠。

### 2.4 CFG / uncond(F1):null prompt dropout

DMD `_compute_kl_grad` 调 `real_score` 两次(cond + uncond)做 CFG(`dmd.py:102-112`)。Phase 2 训练时 null prompt dropout `p = 0.1`(paper 默认),cond + uncond 两条路径都被 LoRA 见过 → Phase 3 调用一致。

null prompt embedding 通过 `WanTextEncoder([""])` 取一次,缓存 reuse(`text_encoder` forward 不便宜)。

## 3. 训练超参

| 项 | 值 | 来源 / 理由 |
|---|---|---|
| LoRA rank | 64 | motion-only 比 full distillation(student LoRA rank 256)轻;paper UNet3D 用 32,Wan-14B 大 ~28× 取中 |
| LoRA alpha | 64(scaling = 1.0) | paper 默认 alpha = rank |
| LoRA dropout | 0 | Wan-14B 已大,无需 LoRA dropout(paper UNet3D 用 0.1) |
| target_modules | `WanAttentionBlock` 内全 Linear(Q/K/V/out + FFN) | 跟 `lora_utils.py` `fake_score` 同 attention block,target 一致 |
| optimizer | AdamW | paper |
| LR | 5e-5 起步 | paper 是 5e-4 on UNet3D 384²;Wan-14B 大 ~28×,起步降一档。不收敛再 scan 1e-4 / 5e-4 |
| weight decay | 0 | paper |
| warmup | linear 50 步 | LoRA 训练常规 |
| precision | bf16 | Wan 默认(`wan_wrapper.py:50`) |
| gradient checkpointing | on | 81f × 480² × Wan-14B 不开 OOM |
| batch size | 1 | paper |
| frame count | 81 | Wan-14B 原生 input shape;对齐 positional encoding |
| resolution | 480² | Wan-14B 原生训练分布 |
| training steps | 500 | 第一版 sanity;recipe 稳后 scan 1000–3000(paper 范围 300–3000) |
| ckpt 频率 | 每 100 步,keep last 5 + final | |
| mid sample | 每 250 步生 1–2 个视频目测 | 不跑 Phase 1 eval(太重) |
| 分布式 | 单 GPU(H200 80GB / A100 80GB) | 第一版;扩 12 motion 时再考虑多卡 |
| null prompt dropout `p` | 0.1 | paper 默认 |

## 4. 接口 / 工程

### 4.1 Adapter attach(D3):扩 core dispatcher + method 调用

`configure_adapter_for_model` 当前 `model_name ∈ {generator, fake_score}`,real_score 不挂 adapter。Phase 2 加一行 elif:

```python
# longlive/utils/lora_utils.py
def configure_adapter_for_model(transformer, model_name, ...):
    if model_name == 'generator':
        adapter_target_modules = ['CausalWanAttentionBlock']
    elif model_name == 'fake_score':
        adapter_target_modules = ['WanAttentionBlock']
    elif model_name == 'real_score':                      # 新增
        adapter_target_modules = ['WanAttentionBlock']    # teacher 跟 fake_score 同 block 结构
    else:
        raise ValueError(f"Invalid model name: {model_name}")
```

这是 dispatcher 新增 branch 而非修改现有逻辑,在 "methods 不修改 core" 原则的 acceptable 范围内。Phase 2 trainer 通过 `model_name='real_score'` 调用,Phase 3 同路径加载 → 完全一致。

### 4.2 Forward signature(A1)

Phase 2 LoRA 通过 `WanDiffusionWrapper.forward(noisy_image_or_video, conditional_dict, timestep)` 调用,跟 Phase 3 `real_score(...)` 一致,返回 `(flow_pred, pred_x0)`。不另造接口。

### 4.3 Reference dataset(E)

```
$LL_DATA/ucf_sports/videos/Skateboarding/*.mp4     (Phase 1 已落地)
  → decord 读 → frames (T, H, W, 3) uint8
  → temporal subsample to 81 frame
        (clip > 81: uniform stride sample;
         clip < 81: loop padding 或 reflect padding)
  → resize + center crop to 480²
  → normalize to [-1, 1]
  → permute to (1, C, T, H, W)
  → WanVAEWrapper.encode_to_latent → (1, F_latent, 16, H/8, W/8)
```

复用 `longlive/utils/wan_wrapper.py:WanVAEWrapper.encode_to_latent`(line 160-174)。

UCF Skateboarding clips 数 N 在 Phase 1 `$LL_DATA/ucf_sports/manifest.csv` 已记录。每个 train step 随机一个 clip,encode 后训(encode 较慢,可考虑 offline 预 encode 到 `.pt` cache;第一版先 on-the-fly,瓶颈再优化)。

Caption text:UCF clip 自带 caption(Phase 1 manifest 里有 prompt 列)或固定 `"a person skateboarding"`(paper 风格 — paper 单 motion 训练用 generic prompt)。

## 5. 文件布局 & 训练 loop 骨架

```
longlive/methods/motiondirector/
├── __init__.py                      # 空(没新 adapter type register)
├── train.py                         # standalone entry
├── losses.py                        # L_temporal_MSE + L_AD
├── data.py                          # Skateboarding loader + Wan VAE encode
└── configs/
    └── skateboarding_v1.yaml        # 全部 hyperparams + paths
```

`train.py` 不复用 `ScoreDistillationTrainer`(O1 standalone)。Loop pseudocode:

```python
def main(cfg):
    teacher = WanDiffusionWrapper(model_name='Wan2.1-T2V-14B', is_causal=False)
    teacher = configure_adapter_for_model(teacher, 'real_score', cfg.adapter)
    teacher.enable_gradient_checkpointing()

    text_encoder = WanTextEncoder()
    vae = WanVAEWrapper()
    scheduler = teacher.scheduler                   # FlowMatchScheduler

    dataset = SkateboardingLatentDataset(
        clips_dir=f"{cfg.ll_data}/ucf_sports/videos/Skateboarding",
        manifest=f"{cfg.ll_data}/ucf_sports/manifest.csv",
        vae=vae, frame_count=81, resolution=480,
    )

    optimizer = AdamW(
        filter(lambda p: p.requires_grad, teacher.parameters()),
        lr=cfg.lr, weight_decay=0
    )
    lr_sched = get_linear_warmup_schedule(optimizer, warmup_steps=50)

    null_embed = text_encoder([""])                 # cached uncond

    for step in range(cfg.train_steps):
        latent, prompt = dataset.sample()           # (1, F, C, H, W), str

        # text embed with null dropout
        if random.random() < cfg.null_prompt_p:
            cond_dict = null_embed
        else:
            cond_dict = text_encoder([prompt])

        # add noise
        noise = torch.randn_like(latent)
        t = torch.randint(20, 980, (1,), device=latent.device)
        noisy = scheduler.add_noise(latent.flatten(0,1), noise.flatten(0,1), t)\
                         .unflatten(0, latent.shape[:2])

        # forward + ε reverse
        flow_pred, pred_x0 = teacher(noisy, cond_dict, t.expand(latent.shape[:2]))
        eps_pred = flow_pred + pred_x0

        # loss
        loss_mse = F.mse_loss(eps_pred, noise)
        loss_ad = appearance_debias_loss(eps_pred, noise,
                                          alpha=math.sqrt(2.0), beta=1.0)
        loss = loss_mse + loss_ad

        loss.backward()
        optimizer.step(); lr_sched.step(); optimizer.zero_grad()

        # ckpt + sample
        if step % 100 == 0 and step > 0:
            save_lora_ckpt(teacher, cfg.out_dir, step)
        if step % 250 == 0:
            run_mid_sample(teacher, val_prompts, out_dir=cfg.out_dir, step=step)

    save_lora_ckpt(teacher, cfg.out_dir, "final")
```

## 7. Risks

1. **Wan-14B + 81f × 480² × LoRA backward 显存峰值**:gradient checkpointing on bf16 估 ~60 GB,但 LoRA backward 路径会激活全 attention 计算图。第一次 forward+backward 需要在单 H200 上 sanity → OOM 就降 frame count 到 49 / 33,或者升 4-GPU FSDP(K2)。
2. **B1 反解的 `(1−σ_t)` 梯度衰减**:高 t LoRA 几乎不被更新。若 Phase 3 评估时 LoRA score 在高 t 退化到 base Wan 行为,考虑加 loss weighting(如 `loss_mse * (1 / max(σ_t, 0.1))`)或者 t 采样偏向低 t。
3. **paper LR=5e-4 在 Wan 上太大**:第一版 5e-5,若 500 步 loss 没下降再 scan up。
4. **single motion overfitting**:Skateboarding 只用 1 类 reference,LoRA 可能 overfit 该 motion 的 appearance(违背 L_AD debias 目标)。500 步是 conservative,如果 mid-sample 显示 appearance overfit,降到 300 步或加 LoRA dropout。
5. **null prompt embedding shape**:`WanTextEncoder([""])` 输出 shape 需跟正常 prompt 一致才能 cache。第一次 forward 时 assert。
6. **UCF clip 长度 vs 81 frame**:Skateboarding 各 clip 长度不一,sub-81 frame 的 clip 用 loop padding 处理。第一版的实现先简化,长度统计落地后再考虑加权采样。
7. **encode 速度**:on-the-fly VAE encode 每步开销不小,若发现 bottleneck,offline 预 encode 到 `$LL_DATA/ucf_sports/latents/Skateboarding/*.pt`。

## 8. 验收标准

第一版跑通 = 满足全部:

- 500 步训完无 OOM、无 NaN
- `loss_mse + loss_ad` 总体单调下降或近单调(不必收敛到平台)
- 训完的 `teacher_lora.pt` 加载到 `real_score` 接口能正常 forward,输出 finite tensor、shape 一致
- 250 步 mid-sample 至少有一张视频在视觉上 plausible(滑板 motion 大致正确,subject 不变形)

任一条不满足 → 回看 §2 物理设计(B1/C1/F1/P1),不靠 hyperparam 蒙。
