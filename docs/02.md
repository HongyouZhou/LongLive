## 1. 背景 — 5 个失败 ckpt 的共同失败模式

| ckpt | 变量 | UCF Skateboarding motion_fidelity | Δ vs BASE |
|---|---|---|---|
| BASE | 无 finetune | 0.354 | 0 |
| +AD | eps L_MSE + L_AD,anchor_only,rank 256,12 clips | 0.255 | -0.099 |
| no_AD | eps L_MSE,L_AD off,其它同上 | 0.225 | -0.129 |
| paperstyle | eps L_MSE + L_AD,uniform t,rank 32,1 clip | 0.194 | -0.160 |
| x0space | x0 L_MSE + L_AD,anchor_only,rank 256,12 clips | 0.035 | -0.319 |

所有 ckpt 都 regress。failure 不是 hyperparam 调错,是 **MotionDirector L_MSE 这个 supervision family 跟 DMD few-step student 在数学上不兼容**:

DMD 把 50-step trajectory 压缩到 4 anchor,每 anchor 承担 ~25% output。L_MSE 在 4 anchor 上 pointwise 监督时,每个 anchor 的梯度信号都足以 strong-arm LoRA"在该 anchor 上吐 reference x0"——LoRA 学的不是 motion,是"在任意 caption 下吐 reference 视频的某帧"。x0space 是这套机理的极端:σ² 加权把最强梯度放在 t=1000(纯噪声),LoRA 学到"任意 caption + 任意 noise → reference x0"。

机理细节见 conversation summary 与 [00.md §2](00.md)。

## 2. 设计原则 — 5 篇 deep read 提炼

每篇都在试图绕过同一个数学事实:**few-step 把 supervision 信号集中到极少 anchor,任何 pointwise MSE 都过载这些点**。它们的绕法不同,但有共同 substrate change:

| paper | substrate 改了什么 |
|---|---|
| Yatim DMT(arxiv:2311.17009) | supervision target = 帧对 SMM feature 差,zero training |
| MotionClone(arxiv:2406.05338) | top-k sparse temporal attention mask matching,zero training |
| VMC(arxiv:2312.00845) | **cosine sim** on **inter-frame eps residuals**,finetune temporal attention |
| DiffusionNFT(arxiv:2509.16117) | DMD-style self-normalized weighting + reward-tilted contrastive,off-policy |
| MoGAN(arxiv:2511.21592) | adversarial loss on optical-flow space + DMD anchor,full-param |

四个独立的 design choices 可以正交:

- **比较单位**:点 → **关系**(VMC residual / DMT 帧对 / MotionClone attention map)
- **比较空间**:eps / x0 → 特征 / attention / 光流 / **latent 轨迹切线**
- **比较来源**:offline target → **student 自己的 rollout**
- **比较目标**:单 reference 重建 → **关系结构匹配**

我们之前只动了 "比较空间"(eps vs x0)这一维。**这个 sketch 同时动三维:比较单位(改为关系)+ 比较空间(latent 而不是 eps)+ 比较目标(关系结构,不是绝对值)**。

## 3. Loss 设计

### 3.1 Motion term — latent inter-frame delta cosine

**Setup**:

- Reference clip `x_ref ∈ R^{T_pixel × 3 × H_pixel × W_pixel}` → VAE encode → `z_ref ∈ R^{F × C × H × W}`,F=21 latent frames(81 pixel frames @ Wan VAE temporal compression 4×)。
- 训练每步 sample anchor `t_k ∈ {1000, 750, 500, 250}` 与噪声 `ε`。
- noisy 状态:`noisy = (1−σ_k)·z_ref + σ_k·ε`(标准 forward,沿用 train.py 现有逻辑)。
- 学生前向:`flow_pred, pred_x0_s ← generator(noisy, cond, t_k)`,`pred_x0_s ∈ R^{F × C × H × W}`。

**Inter-frame delta**(latent 空间,沿 frame 维度):

```
Δs[f, k] = pred_x0_s[f+1] − pred_x0_s[f]       student,依赖 anchor t_k
Δr[f]    = z_ref[f+1]      − z_ref[f]           reference,clean,anchor-independent
```

`f ∈ {0, ..., F−2}`,共 `F−1 = 20` 个帧对。

**Cosine loss**:

```
L_motion = (1 / ((F−1)·K)) · Σ_k Σ_f  (1 − cos(Δs[f, k], Δr[f]))
```

cosine 在 flatten `C·H·W` 后算,每 step 跑 `K=4` 个 anchor(或单步只跑 1 个 anchor,K=1,4 步累加;实施时按梯度积累方便选)。

**为什么这个形式解决前面的失败**:

1. **跨 anchor 同时供梯度**:loss 的最小单位是 `(f, k)` pair,K 个 anchor 共享同一个 Δr[f] 作为 target → LoRA 不能在某个 anchor 上单独 strong-arm,因为对其它 anchor 而言它也得维持一致 direction。
2. **Cosine 是 scale-invariant**:LoRA 不能通过"把所有 pred 都拉到 reference 那个特定向量"hijack loss——因为 cosine 看不到 magnitude。同 [VMC](https://arxiv.org/abs/2312.00845)。
3. **Inter-frame delta 自动 cancel 帧不变的 appearance**:reference 视频里固定不变的 subject/scene 在 `z_ref[f+1] − z_ref[f]` 里减没了,留下来的只是"帧间相对变化结构" = motion 的 fundamental encoding。**L_AD 想做但做不彻底的事**。
4. **Latent 空间 native to Wan**:不需要选 UNet decoder block(DMT 那种 architecture-dependent choice)——VAE-encoded latent 就是 Wan 的原生表达。

### 3.2 Anchor term — prior consistency on non-reference prompts

需要一个 general prompt dataset(50-100 个 OpenVid clip 即可)。Per step:

- Sample `(z_gen, c_gen)` 从 general dataset。
- Sample anchor `t_k`,噪声 `ε_gen`。
- `noisy_gen = (1−σ_k)·z_gen + σ_k·ε_gen`。
- `pred_x0_lora = generator_with_lora(noisy_gen, c_gen, t_k)`。
- `pred_x0_base = generator_without_lora(noisy_gen, c_gen, t_k)` — 通过 PEFT `disable_adapter()` context 拿(NFT 同款 trick)。

**Loss**:

```
L_anchor = MSE(pred_x0_lora, sg(pred_x0_base))
```

`sg` 是 stop-gradient。LoRA 不能漂离 base 在 non-reference prompt 上的行为。

**为什么需要这个**:

- 单独 L_motion 会让 LoRA 在 reference prompt 上做对的事,但在其它 prompt 上无约束,LoRA 可能 generalize 成"在所有 prompt 上都偏 reference 的 motion pattern"。这个 anchor 项强迫 base 行为在 non-reference 上保持。
- 同 NFT 的隐藏 KL 项(`||v_θ − v_base_no_LoRA||²`)、Noise Consistency Regularization 的 prior-consistency loss、LaSRO 的 L_lcm anchor。三个独立 paper 都 converge 到这个设计原则:**finetune 必须有 anti-drift regularizer**。

### 3.3 总损失

```
L = λ_motion · L_motion + λ_anchor · L_anchor
```

初始权重:`λ_motion = 1.0`,`λ_anchor = 1.0`。tuning 范围 [0.1, 10]。

**注意**:没有 L_MSE on eps、没有 L_AD。两者都被 motion term 的 inter-frame delta + cosine 结构吸收 / 替代。**这是跟 MotionDirector 显著不同的清洁断面**。

## 5. 实施 skeleton

### 5.1 `losses.py`(新增,~50 LOC)

```python
def trajectory_cosine_loss(pred_x0_s, z_ref):
    """L_motion = mean over (f,k) of (1 − cos(Δs[f,k], Δr[f])).

    Args:
        pred_x0_s: (B, F, C, H, W)  student's predicted clean latent at one anchor.
        z_ref:     (B, F, C, H, W)  reference clip's clean latent (VAE-encoded).
    Returns: scalar loss.
    """
    delta_s = pred_x0_s[:, 1:] - pred_x0_s[:, :-1]   # (B, F-1, C, H, W)
    delta_r = z_ref[:, 1:]      - z_ref[:, :-1]
    delta_s = delta_s.flatten(2)                     # (B, F-1, C*H*W)
    delta_r = delta_r.flatten(2)
    cos = F.cosine_similarity(delta_s, delta_r, dim=-1, eps=1e-8)
    return (1.0 - cos).mean()


def prior_consistency_loss(pred_x0_lora, pred_x0_base):
    """L_anchor = MSE(LoRA-on prediction, sg(LoRA-off prediction))."""
    return F.mse_loss(pred_x0_lora, pred_x0_base.detach())
```

### 5.3 `train.py`(修改 ~70 LOC)

每 step 同时 sample reference batch + general batch:

```python
# === reference batch (for L_motion) ===
z_ref, _ = ref_dataset.sample()
noise = randn_like(z_ref)
t_k = sample_anchor(cfg.t_anchors)
noisy_ref = sched.add_noise(z_ref, noise, t_k)
flow_pred, pred_x0_s = generator(noisy_ref, ref_cond, t_k)
L_motion = trajectory_cosine_loss(pred_x0_s, z_ref)

# === general batch (for L_anchor) ===
z_gen, c_gen = general_dataset.sample()
# encode c_gen on the fly OR pre-cache embeddings
gen_cond = text_encoder([c_gen])  # or pre-cached
noise_gen = randn_like(z_gen)
t_k_g = sample_anchor(cfg.t_anchors)
noisy_gen = sched.add_noise(z_gen, noise_gen, t_k_g)

# LoRA on
_, pred_x0_lora = generator(noisy_gen, gen_cond, t_k_g)
# LoRA off
with generator.model.disable_adapter():
    with torch.no_grad():
        _, pred_x0_base = generator(noisy_gen, gen_cond, t_k_g)
L_anchor = prior_consistency_loss(pred_x0_lora, pred_x0_base)

# === total ===
loss = cfg.lambda_motion * L_motion + cfg.lambda_anchor * L_anchor
loss.backward()
optimizer.step()
```

注意:`disable_adapter` 需要在 PEFT 0.10+ 下 work,且要兼容 FSDP wrap。需要 1 小时 smoke 验证。

## 7. Ablations(按优先级)

| 变量 | 取值 | 答的问题 |
|---|---|---|
| `λ_motion / λ_anchor` | `0.1`,`0.5`,`1.0`,`5.0`,`10.0` ratio | motion 信号强度 vs anti-drift 强度的 sweet spot |
| anchor 子集 | all 4 / {750, 500} / {750} only | motion 是否真主要在中间 anchor([Characterizing Motion Encoding](https://arxiv.org/abs/2512.22175)) |
| cosine 维度 | flatten C·H·W / per-channel mean / 空间 pool 后 | 高维 cosine 是否 saturate(见 §8 Risk 2) |
| `Δr` 计算 | `z[f+1] − z[f]` / `z[f+2] − z[f]` | 短期 vs 中期 motion |
| supervision space | `pred_x0` / `flow_pred` | latent x0 vs velocity 哪个更适合 cosine |
| L_anchor 形式 | MSE / cosine 同款形式 | KL-like anti-drift vs structural anti-drift |

第一波只跑 `λ` ratio sweep + anchor 子集 sweep = 6-8 config,半天 HPC 算力。

## 8. Risks 与 unknowns

### Risk 1:cosine amplitude blind,motion magnitude 可能塌

Cosine 只约束 direction,LoRA 可能学到 "direction 对但 amplitude 小" → `dynamic_score` 跌 / motion_fidelity 跌(CoTracker 既看 direction 也看 magnitude)。

**Mitigation**:如果观察到 amplitude 塌,加 single-sided amplitude term:
```python
L_amp = (max(0, ||Δr|| − ||Δs||))²    # 只惩罚 Δs 比 Δr 小
```
total = λ_motion·L_motion + λ_amp·L_amp + λ_anchor·L_anchor。先 plain cosine 测,再决定。

### Risk 2:高维 cosine 数值范围塌缩

`C·H·W = 16·30·52 = 24,960` 维。两个独立随机向量的 cosine ~ `N(0, 1/24960)`,|cos| 期望 ~0.006。即便 Δs 跟 Δr 高度相关,cosine 数值可能也只到 0.1-0.3。这本身不是问题(loss 仍可优化),但**gradient 信号强度可能不够**。

**Mitigation**(按代价递增):
1. 测得 cosine 数值范围后,如果 < 0.05 全程,改 per-channel cosine 再 mean(16 个 1560 维 cosine,每个 baseline 0.025)
2. 改 spatial pool first(`mean(H, W)` → 16 维 cosine),baseline 0.25,但丢失 spatial structure
3. 改 attention-pooled features:在 Wan DiT 某层取 features,空间 pool 后 cosine(类似 DMT SMM)。代价大。

### Risk 3:`disable_adapter()` × FSDP 兼容性未验证

NFT 用的是 PEFT 0.10 + DDP,我们用的是 PEFT 0.10 + FSDP。`disable_adapter()` 是 context manager,在 FSDP-wrap 后是否仍能正确"短路 LoRA"未确认。**1 小时 smoke check**(单 GPU + FSDP rank 1)。

### Risk 4:general prompt 数据准备

需要 50-100 个 OpenVid clip 当 general prompt source。目前 `$LL_DATA/wm` 下有 OpenVid 训练数据(per memory `reference_motion_data_source`),但不一定有专门的 general subset。

**Mitigation**:写 `scripts/prepare_general_subset.py`,从 OpenVid 随机抽 50 clip + caption,VAE encode + 落 `$LL_DATA/openvid_general_subset/`。~1 小时一次性工作。

### Risk 5:multi-clip motion category 扩展未规划

Smoke / first run 只用 single-clip(skateboard ref)。如果 work,自然扩展是 12 clips category。但 `Δr[f]` 在 12 clips 上需要重新设计:
- 选项 A:每 step 随机选 1 clip,Δr 用该 clip 的 → 不同 step 看不同 motion
- 选项 B:Δr 取 12 clip 的 mean → 学"平均" motion,可能模糊
- 选项 C:contrastive,正样本 = 同 category clip 的 Δr,负样本 = 其它 category

先做 single-clip,看到信号再讨论 multi-clip。

## 9. 研究 contribution(如果 work)

不是 "更好的 MotionDirector"。核心 claim 是:

> **在 distilled few-step video diffusion 上做 reference-based motion customization,supervision 不应该建立在 single-frame 重建(eps / x0 MSE),应该建立在 latent space 的 inter-frame relational structure(cosine on Δ)上,并辅以 prior-consistency anti-drift regularizer。**

跟 VMC 的 cosine + eps-residual 思路同根,但显式扩展到:
1. **Latent x0 space**(不在 eps)— 跟 DMD few-step student 的 native output 对齐
2. **跨 anchor 共享 Δr**(per-anchor 算 Δs,跨 anchor 共一个 target)— 直接利用 4-anchor 结构而不是回避
3. **Prior consistency anti-drift 项**作为必要组件(VMC 没有)

跟 5 个失败 ckpt 的对比表是 paper 的核心 evidence —— **同 base 同 data 同 metric 下,supervision form 单变量替换的效果对比**。

## 11. 为什么 5 个 L_MSE ckpt 没完全塌(理论 vs 实证)

写在 traj_cos eval 出结果后。先记导师提出的理论论断,再用 5 个 ckpt 数据点核对实证,最后说明为什么 traj_cos 跳出了这个论断的适用范围。

### 11.1 导师的理论论断

DMD 蒸馏过的 few-step student 在 4 个 anchor 上的输出是**精心调出的平衡**:

```
t=1000 → 粗稿 (composition / 主体身份)
t=750  → coarse motion
t=500  → 细化运动 / 物体身份
t=250  → 高频纹理
```

整条 trajectory 不是独立的 4 次 denoising,是**学到的 score field composition**——4 步输出彼此衔接才能产生合理样本。

在 t=t_k 处加 MSE supervision 的梯度:
- 沿"匹配 noised target ε_gt"方向走
- 这方向跟"score field 维持"方向**正交**——MSE 目标是 specific noised pair,DMD 蒸馏目标是 distribution matching
- 走得够久够远 → 该 anchor 的输出脱离 composition basin → 整个 4-step inference 塌

**正确的归纳:**

> **full-param + uniform t + 高 lr + 多 step + 强 t-weighting → 完全塌**

### 11.2 我们 5 个 L_MSE ckpt 没完全塌的四道保险栓

| 保险栓 | 我们实际配置 | 防护机制 |
|---|---|---|
| A. **LoRA 低 rank** | rank 256(≈ base 0.5%),base 冻 | LoRA 只能在低维子空间扰动,**不能 overwrite score field**,base weights 还在,composition 结构在 |
| B. **anchor-only t** | t ∈ {1000,750,500,250} 4 个点 | MSE 只在 anchor 上扰;anchor 之间 t 完全没碰(注:inference 也只走 anchor,这条保护其实有限) |
| C. **短 train** | 500 步 × bs 1 × 8 卡 ≈ 4k 有效 step | 梯度走不远,卡在 local minimum:**部分 MSE-fit + 部分残留 DMD** |
| D. **t-weighting 不一定加在最危险 t** | `(1−σ)²` 在低 t 强 / `σ²` 在高 t 强 | 不同 weighting 破坏力差很多——见 11.3 |

### 11.3 实测梯度递增 ladder

5 个 L_MSE ckpt 按"激进度"排序,越右越接近导师预言的"完全塌":

| ckpt | 设置激进度 | UCF mf | VBench Total | 距完全塌 |
|---|---|---|---|---|
| BASE | 不动 | 0.354 | 83.09 | 0 |
| +AD | 标准 eps L_MSE + L_AD | 0.255 | 79.88 | -3.2 |
| no_AD | 移除 L_AD regularization | 0.225 | (未跑) | 更远一点 |
| paperstyle | rank **32**(打破 A)+ 1 clip + **uniform t**(打破 B) | 0.194 | 79.69 | 跟 +AD 同档 |
| **x0space** | **x0 space σ²** 加权 → 最强梯度放在 t=1000 | **0.094** | **71.66** | **最接近** |

**x0space 是 5 个里面最接近导师预言的 ckpt**:
- σ² 在 t=1000 ≈ 1.0,**最强梯度放在"纯噪声 → reference x0"映射上**
- 这正是"破坏 score field composition"的极致方向——LoRA 学到"任意 caption + 任意 noise 都 denoise 到 reference"
- VBench Total 71.66(-11.4 vs BASE),imaging_quality 31.31(BASE 的一半),Semantic 63.12(-13)
- **如果加 full-param + 更多 step + 更高 lr,这个 ckpt 就是完全塌的形态**

### 11.4 文献佐证 — 都是"梯度式塌",不是"断崖式塌"

两个独立证据点:

**Z-Image Turbo training adapter writeup**(Ostris,2025):
> "When training Z-Image Turbo like a standard diffusion model, the model **gradually** loses its Turbo behavior, **starting to require more steps and CFG** for good results"

— "gradually"+"starting to" → 渐变过程,不是 instant catastrophe。

**DiffusionNFT Issue #20**(有人 port 到 Wan2.1-14B):
> "the generated video differs significantly from the original video in other dimensions (such as **blurriness and motion distortion**). 99.9% of total_loss is policy_loss"

— 同样是 partial degradation,不是完全失效。

→ 实践里"塌"是**滑动光谱**,不是 0/1 跳变。LoRA + 短 train + 弱 t-weighting 的组合把光谱位置往"functional"端拉。

### 11.5 为什么 traj_cos 跳出这个论断

简单:**它不是 MSE**。

```
cos(Δs, Δr) = ⟨Δs, Δr⟩ / (‖Δs‖·‖Δr‖)
```

跟 MSE 关键差异:

| 性质 | MSE | cosine |
|---|---|---|
| Scale 处理 | 不变 — 越偏离梯度越大 | **invariant** — LoRA 不能 push magnitude 来 hijack |
| 饱和行为 | 永远在 push | **到 cos=1 就停**(梯度饱和) |
| 监督单位 | per-point | **on relations**(帧间 delta) |

所以 traj_cos 不是 "MSE-on-distilled-but-with-safety-nets",**它跳出了 MSE 这个 supervision family**,导师那个论断不适用。

实证一致:traj_cos eval 数据点(写在 11.6)显示 motion_fidelity **第一次胜过 BASE**(+0.082),没有 11.3 那条"激进度 → 越塌"曲线上的位置。

**两类失败模式现在都有了 evidence**:

| 失败模式 | 触发 ckpt | 副作用 |
|---|---|---|

traj_cos 没踩第一类(supervision form 改对了),但踩了第二类(cosine 固有缺陷)。下一步 v2 加 amplitude term 修第二类(`L_amp = max(0, ‖Δr‖ − ‖Δs‖)²`)。

### 11.7 一句话总结

**导师论断 = "MSE-shape supervision + 充分破坏力 = few-step 蒸馏 student 塌"**。我们 5 个 L_MSE ckpt 都被 LoRA + 短 train + 弱 t-weighting 三个保险栓减速到 degraded-but-functional;x0space 是最贴近导师场景的反例数据点(VBench Total -11.4,Semantic -13)。traj_cos 因为不是 MSE,跳出该论断的适用范围,实测也跟预期一致(motion_fidelity 首次 > BASE,但 cosine 带来新失败模式 amplitude collapse,这是下一个修复目标)。
