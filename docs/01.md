# 两类 LoRA 职责分工

路线 1(post-hoc MotionDirector finetune,见 [00.md §1.1](00.md))讨论中会反复出现
"两个 LoRA"的说法 — 这个说法在不同维度有不同所指,务必先对齐维度。

## Framing 范围

| Framing | "两个 LoRA" 分别指 | 用在哪 |
|---|---|---|
| MotionDirector paper 原设计 | **spatial LoRA**(2D spatial attn,吸 appearance)+ **temporal LoRA**(temporal attn,吸 motion) | paper §3.2 |
| LongLive 整个项目 history | **NVlabs `lora.pt`**(few-step capability)+ **我们的 motion LoRA** | 本文档 § 类别对照 / § 加载流程 |
| 我们 branch 当前 forward graph | **1 个 trainable LoRA**(motion LoRA,挂在 `CausalWanAttentionBlock`) | train.py |

本文档主体用 framing 2 描述 NVlabs lora.pt 跟我们 motion LoRA 的层叠关系;framing 1
(paper 原设计)跟当前实现的偏差见 § vs MotionDirector paper 原设计。

## 类别对照

| 维度 | NVlabs `lora.pt` | 我们训的 motion LoRA |
|---|---|---|
| 解决的问题 | 50-step → 4-step capability | 窄分布 → 学 reference motion |
| 训练 loss | DMD backward KL | forward KL on ε + L_AD |
| 监督源 | teacher score(Wan 50-step) | ground-truth video frames |
| 在 KL 谱上 | mode-seeking 这头 | mode-covering 这头 |
| 训练 by | NVlabs(已完成,frozen) | 我们(本 branch) |
| 在 forward 中位置 | merged into base(`merge_and_unload`) | 挂在 merged base 之上(PEFT) |
| rank / target | 256 / `CausalWanAttentionBlock` | 256 / `CausalWanAttentionBlock`(独立) |

rank 数字相同是巧合 — 两层 LoRA 任务正交,我们的 rank 不必跟 NVlabs 对齐。

## vs MotionDirector paper 原设计

paper(§3.2)的 dual-LoRA 设计:

- **spatial LoRA** — 挂在 Transformer2D 的 spatial attention 层,只看 single-frame
  appearance
- **temporal LoRA** — 挂在 Temporal Transformer 的 temporal attention 层,吸
  frame-to-frame motion
- 三项 loss 等权相加:`L = L_temporal_MSE + L_AD + L_spatial`

**我们当前实现 drop 了 spatial LoRA + L_spatial**,理由在 `losses.py` 顶部:

> Wan DiT has no Transformer2D / Temporal split to anchor a separate spatial
> LoRA on.

paper 用的 ModelScope-T2V / ZeroScope 是 `Transformer2DModel` + `TemporalTransformer`
串联结构,天然给 paper 两个清晰的 attach point(2D 块挂 spatial LoRA,3D 块挂 temporal
LoRA)。Wan DiT 是 **unified 3D attention** — 每个 `CausalWanAttentionBlock` 同时
处理 spatial + temporal,没有 2D vs temporal 的拆分层 — paper 的 dual-attach point
在 Wan 上不直接 mappable。

所以我们当前实现是 **temporal-style 单 LoRA + L_temporal_MSE + L_AD**,不是 paper
完整复现。这是 Wan-specific 取舍。

## 路线 2 下的对应结构

路线 2 不分两步,把 ε-space MLE 项直接进 DMD distillation pipeline,与 backward KL
联合优化 — 只剩一个 LoRA,joint 学 "few-step capability + motion coverage"。

- DMD trainer 需要改(加 forward-KL 项),跟"DMD 架构不动"有 tension(见 [00.md §1.2](00.md))
- 两层 LoRA 的概念塌缩为一层
- 本 branch 不走;留作研究备选
