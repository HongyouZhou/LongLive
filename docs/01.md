# 两类 LoRA 职责分工

路线 1(post-hoc MotionDirector finetune,见 [00.md §1.1](00.md))下会出现两个 PEFT
LoRA。它们解决的问题、训练 loss、监督源都不同 — 讨论 / 命名 / 实施时不要混到
same level。本文档描述具体层叠结构,与 [00.md](00.md) 的上层 framing 配合。

## 类别对照

| 维度 | NVlabs `lora.pt` | 我们训的 motion LoRA |
|---|---|---|
| 解决的问题 | 50-step → 4-step capability | 窄分布 → 学 reference motion |
| 训练 loss | DMD backward KL | forward KL on ε + L_AD |
| 监督源 | teacher score(Wan 50-step) | ground-truth video frames |
| 在 KL 谱上 | mode-seeking 这头 | mode-covering 这头 |
| 训练 by | NVlabs(已完成,frozen) | 我们(本 branch) |
| 在 forward 中位置 | merged into base(`merge_and_unload`) | 挂在 merged base 之上(PEFT) |
| rank / target | 256 / `CausalWanAttentionBlock` | 256 / `CausalWanAttentionBlock`(独立) |

rank 数字相同是巧合 — 两层 LoRA 任务正交,我们的 rank 不必跟 NVlabs 对齐。

## 加载流程

```
═══════════════════════════════════════════════════════════════════════════════
  阶段 A:NVlabs 已完成(frozen 起点,我们不重训)
═══════════════════════════════════════════════════════════════════════════════

     Wan2.1-T2V-1.3B base
              │
              │  ── DMD distillation pipeline ──
              │     teacher = Wan2.1 50-step
              │     gen     = student(few-step)
              │     trainable: lora.pt  (rank 256 on CausalWanAttentionBlock)
              │     loss:     backward KL on teacher score
              │     问题:    mode-seeking → 窄分布(motion amplitude 塌陷)
              ▼
     longlive_base.pt + lora.pt
     ───────────────────────────
     = NVlabs few-step inference product

═══════════════════════════════════════════════════════════════════════════════
  阶段 B:候选 idea 1 — post-hoc MotionDirector finetune(我们做的)
═══════════════════════════════════════════════════════════════════════════════

  Step 1  wrapper.load_state_dict(longlive_base.pt)          ← wrapper-level load
  Step 2  configure_adapter_for_model(..., baseline_adapter)
  Step 3  set_peft_model_state_dict(lora.pt)
  Step 4  merge_and_unload()                                  ← clean 起点
              │
              ▼
       frozen base  (= NVlabs 产物的展开形式)
              │
  Step 5  configure_adapter_for_model(..., adapter)           ← 我们的 LoRA
              │
  Step 6  training loop(single-caption MLE on UCF Skateboarding):
              │
              │   ref clip ── VAE ──► latent
              │                        │
              │                        ▼
              │                 add_noise(t ∈ {1000,750,500,250})
              │                        │
              │                        ▼
              │              generator(noisy, t, cond)
              │                        │
              │              flow_pred, pred_x0
              │                        │
              │              eps_pred = flow_pred + pred_x0   ← B1 close-form reverse
              │                        │
              │                        ▼
              │   loss = MSE(eps_pred, eps_gt)                ← L_temporal_MSE
              │          + AD(eps_pred, eps_gt; α=√2, β=1)    ← L_AD
              │
              ▼
       motion LoRA(idea-layer)
              │
              │  inference: NVlabs few-step model 之上 ⊕ 这层 LoRA
              ▼
       motion-customized few-step generator
```

## 路线 2 下的对应结构

路线 2 不分两步,把 ε-space MLE 项直接进 DMD distillation pipeline,与 backward KL
联合优化 — 只剩一个 LoRA,joint 学 "few-step capability + motion coverage"。

- DMD trainer 需要改(加 forward-KL 项),跟"DMD 架构不动"有 tension(见 [00.md §1.2](00.md))
- 两层 LoRA 的概念塌缩为一层
- 本 branch 不走;留作研究备选

## 实施 anchor(train.py 步骤映射)

`longlive/methods/motiondirector/train.py`:

- Step 1-4 ↔ `baseline_adapter` + `baseline_lora_ckpt`(`merge_and_unload()` 结束)

- Step 6 ↔ `losses.appearance_debias_loss` + `F.mse_loss`,t 从 `cfg.t_anchors` 采样

upstream alignment 见 NVlabs `configs/longlive_inference.yaml` + `inference.py` LoRA 段:
字段(model_name / timestep_shift / local_attn_size / sink_size / rank / alpha)全对齐;
