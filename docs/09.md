# Residual-Bucket Motion Reward

## 1. Why This Experiment

The reward-weighted velocity experiment did not fix the visible motion mismatch:

| Method | UCF Golf-Swing motion_fidelity | LOVEU miami-surf motion_fidelity |
|---|---:|---:|
| BASE | 0.329 | 0.756 |
| MP-EM-RAM 4x8 absolute | 0.078 | 0.934 |
| MP-EM-RAM reward-weighted velocity | 0.211 | 0.754 |

This suggests the immediate bottleneck is not only where the scalar reward enters
the M-step.  The scalar itself loses the motion structure we care about.

## 2. Reference-Motion Diagnostic

The descriptor diagnostic removes robust global translation, selects moving
residual tracklets, and compares early/middle/late temporal buckets.

For UCF Golf-Swing, generated videos had much larger residual speed than the
reference and opposite bucket directions in early/late motion.  This explains
why high dynamic score can coexist with poor visual motion match.

For LOVEU miami-surf, the average residual score was better, but middle/late
buckets still pointed against the reference.  The failure is therefore visible
in the reward signal before changing the velocity target.

## 3. Implementation

The executable switch stays inside `motion_projected_em_ram`:

```yaml
reward_motion_mode: residual_bucket
reward_bucket_count: 3
reward_moving_percentile: 60.0
reward_min_moving_tracks: 4
reward_moving_speed_floor: 1.0e-5
```

`tracklet_scalar` remains the default reward and preserves the previous
Yatim-style direction plus speed-ratio score.

`residual_bucket` changes only the reward extraction:

```text
CoTracker tracks
-> normalize by video size
-> subtract per-frame median global translation
-> keep moving residual tracklets
-> compare residual direction/speed plus temporal bucket diagnostics
```

The M-step remains standard alpha-shift MP-EM-RAM for the first run:

```text
target = v_anchor + reward_coef * alpha_i * P_motion(raw_shift)
```

This isolates the question: does a better reference-motion reward choose better
rollouts without introducing a new target-update confound?
