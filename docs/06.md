## 1. 框架:diffusion distillation 的 5 个 loss family

按 loss 形式划分(不按论文先后),所有现代 distillation 落 5 类:

| Family | Loss 类型 | Mode 行为 | 代表 paper |
|---|---|---|---|
| **Reverse-KL distribution matching** | KL(p_θ ∥ p_data) | mode-seeking | DMD [1], DMD2 [2] |
| **Forward-KL / Fisher divergence** | 在 score 域算 ‖∇log p_θ − ∇log p_data‖² | mode-covering | SiD (Score Identity Distillation) [3] |
| **Trajectory regression(consistency)** | L2 on PF-ODE trajectory 上的 self-consistency | 没 KL-style mode 问题,但有 quality 上限 | Consistency Models [4], LCM [5], AnimateLCM [6] |
| **Adversarial** | GAN minimax (近似 JS 散度) | discriminator-defined,经验上接近 mode-covering | ADD / SDXL Turbo [7], DMD2 (GAN as regression-loss replacement) |
| **Hybrid forward+reverse / 多阶段** | 多 loss 串联或并联 | 设计来取长补短 | rCM [8], Causal Forcing [9], T2V-Turbo [10] |

**我们现在在哪**:LongLive = Self-Forcing [11] (Wan-1.3B 上的原始实现) +
Wan-14B 适配。Self-Forcing 框架本身在同一份代码里**同时支持 DMD / SiD /
GAN 三种 loss head**(paper §3.3),并在 Table 2 里实测对比。我们 Phase 3
选了 DMD head。

## 2. 各算法逐项分析

### 2.1 DMD (Distribution Matching Distillation) [1]

**Loss**:
```
∇_θ D_KL(p_fake ∥ p_real) ≃ E_{z,t,x_t} [w_t α_t (s_fake(x_t,t) − s_real(x_t,t)) dG/dθ]
```

reverse-KL。论文 §3.2 **显式承认 mode collapse**:

> "the optimization is susceptible to mode collapse/dropping, where the fake
> dist assigns higher overall density to a subset of the modes."

— DMD paper [1], 第 3.2 节

**DMD 原版的解药**:加 regression loss(λ=0.25),用 teacher 预生成的
noise→image pairs + LPIPS 作 anchor。这是 DMD 防 mode collapse 的关键模块。
论文 Figure 3 直接展示无 regression 时 mode 塌,加了之后两个 mode 都
recover。

**关键问题:LongLive / Self-Forcing 有用这个 regression loss 吗?**
**没有**。Self-Forcing paper §3.3 描述其 DMD 实现是
"minimizes the reverse KL divergence ... by leveraging the score difference",
没提到 regression loss。原因是 Self-Forcing 自身的"holistic autoregressive
rollout"提供 anchor,认为不需要外加 regression。**但这是个 implicit 假设**
— 如果 rollout 自身的 anchor 不够强,collapse 仍会发生。**这可能是我们
amplitude collapse 的部分原因。**

**Reported 性能**(DMD paper):
- ImageNet 64×64 1-step:FID 2.62,接近 teacher 50-step
- COCO 1-step:FID 11.49,SD-1.5 teacher 是 8.83

**Limitations**(quote from paper):
> "a slight quality discrepancy persists between our one-step model and finer
> discretizations of the diffusion sampling path."

视频域应用 → CausVid [12] 把 DMD 扩到视频(Wan-1.3B,4-step,VBench 84.27),
继承 mode-seeking 性质。

### 2.2 DMD2 [2]

**Change vs DMD**:扔掉 regression loss,加 **GAN discriminator** 作 anchor。
明确动机是省 "expensive precomputed noise-image pair dataset construction
(700 A100 days for SDXL)"。

**Two time-scale update rule**:5 fake_score updates per generator update。
**这跟 LongLive `dfake_gen_update_ratio: 5` 完全一致 → LongLive 用的实际是
DMD2 节奏**。

**Diversity 承认**:

> "our distilled generator experiences a slight degradation in image diversity
> compared to the teacher models."

— DMD2 paper [2]

"slight" 是 image domain 的描述。视频域 + 4-step + 14B 是否仍是 "slight"
没有 paper 数据,我们的 −67% amplitude 提供第一手反例 — 至少在 motion
amplitude 这一维度,**不 slight**。

**Multi-step 支持**:DMD2 支持 4-step generation,FID 19.32(COCO,跟 teacher
比有差距但很近)。

### 2.3 SiD (Score Identity Distillation) [3]

**Loss**:Fisher divergence
```
E_{t, x_t ~ p_θ,t} [‖∇log p_θ,t(x_t) − ∇log p_data,t(x_t)‖²]
```

**Mode 行为**:Fisher 散度对 mode 缺失的惩罚是 **forward-KL-like(mode-
covering)** — 在 p_θ 有 mass 而 p_data 没有的地方,score difference 大,
loss 大。**结构上更倾向保留 teacher 分布的全部 mode**,代价是可能保留
一些 teacher 的低质量 mode(quality vs diversity trade-off 的另一端)。

**Self-Forcing Table 2(直接对比,Wan-1.3B + 4-step + same training):**

| Loss head | Total | Quality | Semantic |
|---|---:|---:|---:|
| Self-Forcing (DMD) | 84.31 | 85.07 | **81.28** |
| **Self-Forcing (SiD)** | 84.07 | **85.52** | 78.24 |
| Self-Forcing (GAN) | 83.88 | 85.06 | 79.16 |

SiD 在 Quality 上 +0.45,Semantic −3.04。两个方向不一致,无法说 "SiD 一定
更好"。但 **SiD 的 Quality 优势可能跟 mode coverage 直接相关** —
diversity ↑ → 模型更不容易塌成单一外观 → Quality 评分(VBench 内含
flickering / temporal consistency 等)同步 ↑。这是合理但未被 Self-Forcing
作者 explicitly 拆解的因果。

**视频域用过**:Self-Forcing 自己的 Table 2。除此之外公开 paper 罕见。

**实施成本**:Self-Forcing 代码已经支持(`utils/loss.py` 的 DenoisingLoss
注册表里加 SiD 项),**Phase 3 只需改 yaml `denoising_loss_type` 字段**。
跟 DMD 同 trainer、同数据、同 max_iters、同硬件,完全 plug-replace。
**这是最便宜的可执行实验**。

### 2.4 GAN (JS 散度,Self-Forcing 第三个 head)

**Loss**:经典 minimax GAN,discriminator 区分 "real video" vs "model-
generated video"。

**Mode 行为**:GAN 是经典 mode-collapse 嫌疑犯,但 Self-Forcing Table 2
显示 GAN head 在 Wan-1.3B 4-step 上 Total 83.88,跟 DMD 的 84.31 差距
0.43,不致命。GAN 在我们 setup 下的实际 mode 行为不可预测。

**实施成本**:同 SiD,Self-Forcing 已支持。但加 discriminator 网络是额外
~1B 参数的模型 + 单独优化器 + 平衡 G/D 训练稳定性,工程成本高于 SiD 但
低于换框架。

### 2.5 Consistency Distillation / LCM / AnimateLCM [4, 5, 6]

**Loss**(LCM):
```
L_CD = E [d(f_θ(z_{t_{n+k}}, c, t_{n+k}),  f_{θ⁻}(ẑ^{Ψ}_{t_n}, c, t_n))]
       ↑                                        ↑
       student at t_{n+k}                       EMA target at t_n
```

L2 距离 between student 在两个相邻 timestep 的预测。**核心不是匹配 data
分布,是匹配 self-consistency**(同一 PF-ODE 轨迹上不同点应该映回同一个
x_0)。

**Mode 行为**:**没有 KL-divergence-driven mode-seeking**。Consistency 是
对 trajectory 的 L2 regression,理论上 mode-covering(像 Progressive
Distillation 那样)。LCM paper 不报 mode collapse 分析,但 FID 在 4-step
达 11.10(SD-1.5 baseline 12 step DDIM 给 22.38),diversity 数字上不输。

**视频域**:AnimateLCM [6] 用 "decoupled consistency learning" 把图像
prior 和 motion prior 分开蒸馏。**没 explicit amplitude 分析**,但 paper
强调 "4-step 视频质量接近教师",且没出现 DMD2 那种 "slight diversity
degradation" disclaimer。

**Limitation**:LCM 在 1-step 上有明显 quality gap("noticeable gap exists
in one-step inference")。4-step 是 sweet spot。

**实施成本**:**整体换框架**。需要重写 trainer。Consistency loss 的训练
特性跟 DMD 不一样(EMA target、self-consistency 而非 score difference)。
**这是 1-2 个月级的投入**。

### 2.6 Adversarial Diffusion Distillation (ADD / LADD) [7]

**Loss**:
```
L = L^G_adv(x̂_θ, φ)  +  λ L_distill(x̂_θ, ψ)
    ↑ hinge GAN loss   ↑ reconstruction
```

- L_adv:discriminator(基于 frozen DINOv2 backbone)用 hinge loss
- L_distill:student 输出 noisy-re-noise 后,teacher denoise,L2 比较

**Mode 行为**:Stability AI 报告:

> "ADD-XL outperforms its teacher model SDXL-Base in quality and prompt
> alignment but with a slight trade-off in sample diversity."

— ADD paper / blog [7]

同样 "slight" 描述。视频域已扩展为 **LADD (Latent Adversarial Diffusion
Distillation)** 用于 SD3 Turbo,以及 **T2V-Turbo** 用于视频。

**Janus artifacts**:论文显示 L_adv 和 L_distill 权重不当时会有 "duplicated
objects" 类幻觉,**mode collapse 的可见症状之一**。weighting 是关键超参。

**视频域 T2V-Turbo [10]**:Consistency Distillation + 多 reward 模型反馈
(包括 motion quality reward)。报告 4-step VBench Total 最高,超过 Gen-2
/ Pika。**reward learning 是 distillation 之外加的层,可能直接对应"加
amplitude-aware 监督信号到 student"这条思路**(docs/02 旧 motion-DMD 路线
的 cleaner 版本)。

**实施成本**:换框架级。

### 2.7 Causal Forcing [9](ICML 2026,直接相关)

**Pipeline**:三阶段,不是单一 loss:

1. **Stage 1**:AR diffusion 训练(teacher 状态)
2. **Stage 2**:Causal **ODE distillation** 或 Causal **Consistency
   distillation**(trajectory-preserving)
3. **Stage 3**:Asymmetric **DMD** as final refinement(bidirectional
   teacher 监督 causal student)

**Direct quote from README**(我们 Phase 3 行为的直接 antibody):

> "the motion dynamics may degrade with excessive DMD training (recommending
> ≤1K steps at batch size 64)"

— Causal Forcing README [9]

**我们 Phase 3 跑了 3000 步**,batch size 8(8 rank × 1)。按 batch size
缩放,相当于 batch=64 的 ~375 步 — **在推荐范围内**。但作者警告
"excessive" 没给具体阈值,2× 推荐值依然可能 over-train。

**Causal Forcing++ 的 2-step model 比 4-step 更好**,因为更少 DMD
refinement = 更少 motion degradation。这反过来印证 amplitude collapse 是
DMD-stage 累积出来的,跟 step 数 / DMD 训练时长正相关。

**最关键的结构性 insight**:把 DMD 当作**最后的 sharpener**(在已经被
ODE/Consistency 训过的 student 上),**不是 from scratch 的 distill 主
力**。这是 docs/05 §5 提到的 "mode-seeking ceiling" 的 architectural
workaround:**不让 DMD 单独负责 distillation**。

**实施成本**:需要 multi-stage pipeline,代码改动比 single-loss 换大,
但比纯 consistency 换框架小(stage 3 还在 DMD 框架内)。中等成本。

### 2.8 rCM (NVlabs ICLR 2026)[8]

**Loss**:**hybrid CM + DMD**,两 loss 同时优化(joint),不是 Causal
Forcing 那种串行。

> "rCM combines forward-divergence (CM) and reverse-divergence (DMD)
> objectives in a joint distillation framework."

— rCM README [8]

**直接 ack 我们关心的问题**:

> "standard sCM excels at quality but lacks diversity ... DMD alone may
> sacrifice quality, sCM alone may reduce variation."

— rCM README [8]

**直接 target Wan-2.1 1.3B**(跟 Self-Forcing 同 base model),Visual
comparison 跟 **DMD2 和 SiD** 对比 — 这是迄今为止跟我们 setup 最近的工作。

**FlashAttention-2 JVP kernel**:efficient gradient through Jacobian-vector
products,scale 到 10B+ 模型。**Wan-14B 直接适用,不需要降维**。

**实施成本**:需要把 rCM 的 sCM 部分接进 Self-Forcing 框架。如果 rCM
release code 是基于类似 Self-Forcing 的 codebase,移植成本中等。否则需要
从 NVlabs 仓库迁移到 LongLive 框架,工作量较大。**这是研究上最 promising
的候选**,但工程难度需要先做 due diligence。

### 2.9 Rectified Flow / Reflow [13](额外参考)

**Procedure**:重训 flow,让 ODE 轨迹更直 → 几步 Euler 就能积分。

**Mode 行为**:rectification 操作是 transport-preserving,理论上不丢
mode。

**对我们的相关性**:Wan-14B 用 flow matching native,reflow 理论上适用。
但 reflow **不是 distillation**,是 **重训 base model**(改 flow 本身),
不是后训练 student。**跟当前 LongLive 框架不兼容**(没有"student"概念了),
属于完全 redefining 我们的 setup。**目前不推荐**。

### 2.10 Progressive Distillation [14](历史参考)

Iterative halving:50-step → 25 → 12 → 6 → 3 → 1。每步 distill 用 L2 on
denoised x_0。已经被 Consistency Distillation 实质上 superseded,但概念
上是 trajectory-regression 类的祖先,**不是 mode-seeking**。

视频域有零星应用但没成为主流。**实施成本极高**(每 halving 都要训一轮),
**不推荐**。

## 3. 跨论文模式总结

把上面 7-9 个候选做横向对比:

| 算法 | Loss 类型 | Mode 行为 | 视频域应用 | 跟 Wan-14B 兼容度 | 工程成本 | 预期 amplitude 改善 |
|---|---|---|---|:---:|:---:|:---:|
| DMD (现在) | reverse-KL | mode-seeking | CausVid, Self-Forcing | ✓ baseline | — | — |
| DMD2 | reverse-KL + GAN | slight diversity loss | (无直接) | △ 需加 D | M | 不确定 |
| **SiD** | Fisher (~ forward-KL) | mode-covering | Self-Forcing Table 2 | **✓ 同代码 swap** | **S(改一行 yaml)** | **可能(待测)** |
| GAN head | JS via D | discriminator-定义 | Self-Forcing Table 2 | △ 需加 D | M | 不确定 |
| Consistency / LCM | L2 trajectory | mode-covering | AnimateLCM | △ 重写 trainer | L | 高 |
| ADD / LADD | GAN + reconstr | slight diversity loss | T2V-Turbo | △ 重写 trainer + D | L | 中 |
| **Causal Forcing** | ODE/CD → DMD (3-stage) | DMD 只做 final | 直接 Wan + 4-step | △ multi-stage | M-L | **高(作者直说 fix motion degradation)** |
| **rCM** | hybrid CM + DMD (joint) | 设计来 balance | **直接 Wan-2.1 1.3B** | △ JVP kernel | M-L | **高(显式 target our problem)** |
| Rectified Flow | flow retraining | preserved | (无视频应用) | ✗ redefines setup | XL | N/A |

行的颜色等级:
- **加粗** = 强候选,既相关又可执行
- 其他 = 参考 / 不推荐

## 4. 我们 Eval 协议本身需要改

无论换 / 不换 algo,**当前 motion_eval 协议**(`docs/03.md` 的 4-metric:
app_div / temp_consist / pick_score / motion_fidelity)有结构性盲点:
**全部 4 个 metric 都不直接测 amplitude**。motion_fidelity 用 CoTracker3
cosine,显式不惩罚幅度衰减。

### 4.1 VBench Dynamic Degree

**已成为 community 标准**。来自 VBench [15] 的 16 个 dimension 之一:

> "Dynamic Degree is designed to assess the extent to which models tend to
> generate non-static videos, as some models tend to generate static videos
> even when the prompt includes descriptions of movement."
>
> "The metric uses RAFT to estimate optical flow strengths between
> consecutive frames of a generated video, and takes the average of the
> largest 5% optical flows ... as the basis to determine whether the video
> is static."

— VBench [15]

**RAFT 光流 vs 我们的 CoTracker tracklet velocity**:本质同一类信号,实现
不同。VBench 用 RAFT + top-5% aggregation,我们的 amplitude_analysis 用
CoTracker3 + mean velocity。RAFT 在 community 里更标准,**采用 VBench
Dynamic Degree 让我们的数字可以跟 paper 直接比**。

### 4.2 实施建议

**优先级 P0**:把 VBench Dynamic Degree 加进 `scripts/motion_eval/run_eval.py`
作为第 5 个 metric。**post-hoc,不动训练,纯加分析**。

未来所有 distillation 算法对比都默认报这 5 个 metric,不再让 amplitude
塌成"看不见的代价"。

### 4.3 还可以加但不优先

- **VBench Motion Smoothness**:RAFT 流的 jitter / discontinuity 测温。
  我们 temp_consist(CLIP frame-pair similarity)只测语义连续,不测 motion
  连续。补这一项可以分离 "smooth motion" 跟 "no motion"。
- **VMBench [16]**:更新的 perception-aligned motion benchmark(2025),
  人评对齐更好,但还没成 standard。

## 5. Sanity check:我们自己的 DMD 是否带 regression loss?

DMD paper §3.2 明确"regression loss 是防 mode collapse 的关键"。
DMD2 用 GAN 替换 regression loss。**Self-Forcing 用什么?**

Self-Forcing paper §3.3 描述 DMD head 时**没提 regression loss**:

> "Distribution Matching Distillation (DMD): This approach minimizes the
> reverse KL divergence ... by leveraging the score difference between
> distributions to guide gradient updates."

— Self-Forcing paper [11]

paper 的 implicit 假设是 "autoregressive self-rollout 提供 anchor,不需要
regression loss"。但 self-rollout anchor 的强度跟 model size、step count、
data diversity 都相关 —— Self-Forcing 自己测的是 Wan-**1.3B**,我们用
Wan-**14B**,model capacity 大 10×,**self-rollout anchor 可能相对变弱**,
mode collapse 风险变高。

**这是个待 verify 的具体假设**。直接查 `longlive/utils/loss.py` 看 DMD
loss 实现里有没有 regression term;如果没有,这就是一条可以加但**会违反
`dmd_architecture_frozen` 的"不缝 loss"原则**的路 —— 因为加 regression
loss = 在 DMD step 里多缝一个 L2,正是 memory 防的事。

放进 docs/06 是 awareness。不作为推荐路径。

## 6. 排除掉什么

按当前 scope memory + 上面 §3 表格,**不在 shortlist**:
- **加 motion-aware loss 到 student**(docs/05 §6 旧候选):违反
  `dmd_architecture_frozen` 第一原则。除非用 reward-learning 形式(像
  T2V-Turbo),不直接缝进 DMD step。
- **Rectified Flow / 重训 base**:redefines setup,不在 distillation 范围。
- **Progressive Distillation**:被 Consistency 实质 superseded,不值得。
- **Phase 2 / 3 超参网格搜索**:`dmd_4step_amplitude_ceiling` 已排除。
- **加 LoRA inference-time scaling**:alpha sweep null result,已证伪。

## 7. Ranked shortlist(给用户选)

按 **(预期改善 motion amplitude) × (1 / 工程成本)** 排序:

### S 级(立即可做,几乎零成本)

**1. VBench Dynamic Degree 接进 motion_eval**(§4.1)
- 改 scripts/motion_eval/run_eval.py,加 RAFT 计算 + top-5% aggregation
- 重跑现有 baseline / phase3 / alpha_sweep eval(用 cached videos),拿
  Dynamic Degree 数字
- 所有后续实验自动 report
- **工程成本**:1-2 天。**GPU 成本**:重跑 4 metric 的 1/4(只算
  Dynamic Degree)
- **不动模型,不动训练**。

### A 级(便宜,直接 plug-replace,能给出一组对比数字)

**2. SiD swap on Phase 3**(§2.3)
- 改 `configs/motion_dmd_skateboarding_v1.yaml` 的 `denoising_loss_type`
  从 `dmd` 改成 `sid`(Self-Forcing 已支持)
- 同 Phase 2 LoRA、同硬件、同 3000 步、同 max_iters
- 训 29h + eval ~30min
- 跟 DMD 直接对比 amplitude / motion_fid / dynamic_degree
- **如果 SiD amplitude 显著高 → Fisher divergence 是 mode-covering 的
  empirical evidence,在我们 setup 复现 Self-Forcing 的 Quality 提升**
- **如果 SiD amplitude 也塌 → 排除 "reverse-KL 是 root cause" 假设,
  转向 rCM / Causal Forcing**

### B 级(中等成本,有架构改动)

**3. Causal Forcing 3-stage pipeline**(§2.7)
- Stage 1 = 现有(Self-Forcing AR pretrain)
- Stage 2 加 ODE distillation 或 Consistency distillation pass
- Stage 3 = 现有 DMD,但**严格限制 ≤1K 步**(对照作者建议)
- 验证:DMD-only(我们现在,3000 步) vs 3-stage(stage 3 仅 1K 步)
- 需要新代码 + 多阶段 ckpt 管理。预计 1-2 周实施 + 训练。

**4. rCM hybrid CM+DMD**(§2.8)
- 移植 NVlabs rCM 实现(原为 Wan-2.1 1.3B,我们要 14B)
- 同时优化 CM loss + DMD loss
- 需要 FlashAttention-2 JVP kernel 验证在 H200/H100 上工作
- **研究上最 promising** — 是迄今唯一在 Wan 上 explicitly target
  "DMD 缺多样性 + CM 缺质量" hybrid 的工作
- 预计 2-3 周实施 + 训练。

### C 级(贵,需要 commit)

**5. Pure consistency distillation(AnimateLCM 风格)**
- 重写 trainer 为 consistency loss
- 失去 Self-Forcing 的 holistic rollout 优势(consistency 是 frame-wise
  loss),可能伤其他 metric
- **不推荐除非 SiD/rCM/Causal Forcing 都不行**

**6. T2V-Turbo 风格 reward-augmented consistency**
- consistency 主 loss + 多 reward model 监督(包括 motion quality reward)
- reward learning 本身需要找 / 训 motion-quality reward model(VBench
  Dynamic Degree 作为 differentiable reward?CoTracker 输出?)
- **是 docs/02 旧 motion-DMD loss 路线的 cleanly redesigned 版本**
- 工程量大,但 idea-wise 最 cleanly 解决 amplitude 问题。

## 8. 推荐执行顺序

如果让我画路径,**S → A → 等 evidence 决定 B 或 C**:

```
Step 1 (now, 1-2 天)
  └─ S: VBench Dynamic Degree 接进 eval
       → 现有 Phase 3 / baseline / alpha_sweep 重 eval
       → 得到 Dynamic Degree 数字,固化 amplitude 指标

Step 2 (~ 1.5 天 + 29h 训练)
  └─ A: SiD swap on Phase 3,同 config 只换 loss
       → 训完跑 5-metric eval(含 Dynamic Degree)
       → 与 DMD 直接对比

Decision point (~ 1 周后)
   ├─ SiD amplitude > DMD 显著 (e.g. ≥+30%) → A 是出路
   │    → 后面再看 Causal Forcing 限步是否进一步改善
   │    → docs/07 写 SiD 验证 + 进一步实验
   │
   └─ SiD 跟 DMD 一样塌
        → reverse-KL 不是 root cause,问题更深
        → 进 B 级实验(rCM 或 Causal Forcing)
        → 投入 2-3 周
```

**不在路径里**:这条路径**没有**任何"调 Phase 2 / Phase 3 超参"步骤,
也**没有**改 DMD 内部 loss 的步骤。完全在 §1 的 scope constraints 内。
