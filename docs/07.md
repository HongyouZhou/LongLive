## 1. 重新声明研究目标(用户 2026-05-16 reframe)

**Research question**:

> How do you do **motion customization** on **few-step** video diffusion
> models while preserving **mode coverage** (motion amplitude, sample
> diversity)?

3 个关键词:
- **few-step**:推理 ≤ 4 步 — DMD-style 速度是基础约束
- **mode covering**:不允许 amplitude collapse 这种 distillation 失败模式
- **finetune-able**:用户能用 minimum data 把自己的 motion 注入

**这是 paper-level research,不是工程项目**:
- iteration cost 不是 hard constraint
- contribution 是 algorithmic + empirical,不是 deliverable framework
- 失败也算 contribution(知道 X 不 work 也是知识)

## 2. 现行 Phase 2 → Phase 3 架构的方法论问题

(承接外部评论 + 用户 2026-05-16 reframe)

```
现状(docs/04 + docs/05 实施完的两阶段架构):
  Phase 2:  motion data ─MLE→ many-step Wan-14B + LoRA   (mode-covering 多步 teacher)
                                          │
                                          ▼  DMD reverse-KL distill
  Phase 3:  longlive_base ─DMD with teacher = Phase 2 teacher→ few-step student
                                          │
                                          ▼
                                  ★ amplitude collapse(docs/05 §3-4)
```

**问题诊断**(docs/05 §4 alpha sweep 已实证):
- Phase 2 LoRA 本身不杀 amplitude(full-step teacher 加 LoRA, 10 px/frame)
- Amplitude collapse 发生在 **Phase 3 DMD 蒸馏过程**:teacher 10 → student 2.5
- **motion 知识穿越两层 indirection 后,被 DMD reverse-KL 的 mode-seeking 性质夺回大部分**

**为什么这跟 paper 目标不一致**:
- paper 目标是"在 **few-step 模型** 上做 motion customize"
- 现状架构 finetune 的是 **multi-step teacher**(Phase 2),少步 student 只是 distillation 的产物
- 信息流是 "many-step learn motion → distill 给 few-step",信息丢失发生在 distill 步
- 应该是 "few-step 直接学 motion",信息无 distill 阶段损失

这就是外部评论"你只有一个少步模型,应该直接在少步上 finetune"的方法论 substance。

## 3. 重新设计的核心 idea(用户 2026-05-16 提出)

**MotionDirector × DMD hybrid**:
- DMD 负责 **few-step 性质**(via reverse-KL distillation)
- MotionDirector 负责 **mode covering 性质**(via forward-KL / MLE on data)
- 关键问题:**怎么把两者放在同一个训练里,不互相抵消**

两个具体 implementation flavor:

### 3.1 Option 1:Sequential(顺序 — 用作 paper baseline)

```
Stage 1: 用现成 longlive_base.pt(DMD 已蒸好,mode-seeking few-step)
Stage 2: 在 longlive_base 上挂 LoRA,用 MotionDirector loss
         (L_temporal_MSE + L_AD)继续训练
```

**特点**:
- 没有重训 DMD(stage 1 用已有 ckpt)
- Stage 2 是 plain MLE finetune,不动 DMD trainer
- 最后训练信号是 forward-KL → mode-covering 主导
- **不在 DMD step 里缝 loss**,完全合规 `dmd_architecture_frozen`

**预期效果**:
- amplitude 部分恢复(forward-KL 是最后信号)
- DMD-given sharpness 部分丢失(MLE 是 last shaping)
- few-step 推理可能 break(取决于 LoRA 强度 + timestep sampling 范围)
- **不是 paper main contribution,是 baseline**

### 3.2 Option 2:Joint(联合 — paper main contribution)

```
Stage 1 (teacher pretrain): motion data ─MLE→ many-step Wan-14B + LoRA
                                          │
                                          ▼ (motion-aligned teacher)
Stage 2 (joint distill):    few-step student trained with
                              L_joint = α · L_DMD(student, teacher)
                                      + β · L_MD(student, motion data)
                                          │
                                          ▼
                              few-step student that's mode-covering on motion
```

**特点**:
- Stage 1 跟现行 Phase 2 **完全一致**(产物即 `teacher_lora_final.pt`)
- Stage 2 修改 Phase 3 trainer:在 generator update 里同时计算 L_DMD 和
  L_MD,**加权求和**
- L_MD 在 few-step student 自己的 noise schedule 上做 ε-MSE(B1 close-form 反解)+ L_AD
- 关键 hypothesis:**当 teacher 已经在 motion data 上 pre-aligned 后,
  L_DMD 和 L_MD 的梯度方向接近,不再冲突**

**docs/02 旧 motion-DMD 路线为什么失败**:
- 当时的 setup:`teacher = 原版 Wan-14B`(没见过 motion data)
- L_DMD 把 student 拉向 teacher 分布(无 motion 偏好)
- L_MD 把 student 拉向 motion data
- teacher ≠ data → 两个方向冲突 → 训练发散

**这次为什么应该 work**(待 empirically 验证):
- 当 teacher = Wan-14B + Phase 2 LoRA(已在 motion data 上 MLE 训过)
- teacher 分布已经向 motion data 倾斜
- L_DMD 拉的方向 ≈ L_MD 拉的方向(motion data 是两者共同"target")
- 梯度对齐 → 联合训练稳定 + 两个 benefit 复合

### 3.3 这就反过来验证了 Phase 2 的存在意义

之前我们认为 Phase 2 是 "为了 Phase 3 DMD 给 motion teacher"。
**重新理解后,Phase 2 的真实价值是 "为 Option 2 的联合训练做 gradient alignment"**。

如果 Option 2 不需要 alignment(纯 motion data 也能联合训练),Phase 2 多余;
如果需要,Phase 2 是 Option 2 的 **prerequisite**。
**这本身就是一个 ablation 维度** — paper 必跑。

        - Algorithm spec
        - Failure modes (loses sharpness, may break few-step)
   §4.2 Proposed: aligned joint distillation (Option 2)
        - Stage A: motion-aware teacher pretrain (MotionDirector MLE)
        - Stage B: joint L_DMD + L_MD on student
        - Why alignment matters (Stage A as prerequisite)

§5 Experiments
   §5.1 Setup: Wan-14B, UCF/LOVEU, 5 metrics incl. Dynamic Degree
   §5.2 Baselines
        - longlive_base (no motion training)

   §5.3 Main result: Option 2 with aligned teacher
        - Headline numbers + amplitude restored
   §5.4 Ablations
        - Teacher pretraining on/off (alignment hypothesis test)
        - α / β ratio scan (joint loss weighting)

   §5.5 Negative results / honesty
        - 如果 Option 2 没 net positive 跟 Option 1 比,说"sequential is

   - future work

## 5. Experimental Plan

### 5.1 Phase A: Option 1 (sequential baseline) — **validation experiment**

**目的**:
- 验证"post-DMD MLE finetune 这条路 technically works"
- 量化 sequential 的实际 trade-off(amplitude vs sharpness)
- 提供 paper Table 1 的关键 baseline

**实施**:
- 起点:`longlive_base.pt`(现成)
- 模型:longlive_base + 新 LoRA(rank 待定,建议 64 起 — 跟 Phase 2 同)
- Loss:MotionDirector L_temporal_MSE + L_AD,B1 close-form ε 反解
- Data:UCF Skateboarding(Phase 2 同源,可比)
- 训练步数:500 起(Phase 2 同),可能 ablate 到 200 / 1000
- Timestep sampling 范围:**关键变量** — 限制在 `[1000, 750, 500, 250]` ±50 的 narrow band,vs 全范围 `[20, 980]`,要 ablation
- Eval:5 metric(含 Dynamic Degree)+ amplitude post-hoc

**预算**:~1.5h train + 30min eval per config。3-4 configs 一晚上完事。

**输出**:`docs/08`(实验结果 + paper Table 1 baseline 数字)。

### 5.2 Phase B: Option 2 (aligned joint) — **paper main contribution**

**目的**:
- 验证 alignment hypothesis(teacher pretrain 让联合训练不冲突)
- 验证 amplitude 是否真的恢复
- 找到 α/β operating point

**实施**:
- 代码层面:新建 `MotionDirectorJointDistillTrainer` 子类(或 `JointMotionDMDTrainer`)
- 继承 `ScoreDistillationTrainer`(Phase 3 用的)
- 在 generator update step 里:
  1. 算 L_DMD(标准 DMD 流程)
  2. 算 L_MD(MotionDirector ε-MSE + L_AD,**用 motion data,不是 student 输出**)
  3. `loss = α * L_DMD + β * L_MD`
  4. backward
- α / β 初值:1.0 / 1.0 起,扫到 1.0 / 0.5,1.0 / 0.1,0.5 / 1.0,等
- Data:UCF Skateboarding(同 Phase A)
- 训练步数:跟 Phase 3 同,3000 起
- Eval:同 Phase A + 跟 sequential 直接对比

**预算**:~29h train + 30min eval per config。每个 α/β 设置都要单独训。
计划至少 4-6 个 config,**~7-10 天 wall clock GPU 时间**。

**输出**:`docs/09` + paper Table 2 main result。

### 5.3 关键 ablations(必跑,否则 paper 不能投)

- **A1: teacher pretraining on/off**
  - Option 2 with teacher_lora_final.pt vs Option 2 with vanilla Wan-14B teacher
  - 直接测 alignment hypothesis
- **A2: L_AD on/off**
  - Joint setup with full MotionDirector vs joint setup with只 L_temporal_MSE
  - 测 appearance debias 在 joint 里是否仍 helpful
- **A3: α/β schedule(static vs annealed)**
  - 固定权重 vs schedule(早期 DMD 多 later MD 多,或反过来)
- **A4: timestep sampling range**
  - 跟 Phase A 同 — joint 训练能否在全范围 timestep 上做,还是必须限制到 few-step anchor
- **A5: data scale**
  - 1 motion category vs N category — 是否一致改善

每个 ablation 一组 config。预算 5 个 ablation × ~30h = ~150h GPU = ~1 周。

### 5.4 总时间表(估算)

```
Week 1:    Phase A(Option 1 sequential)实验 + docs/08
Week 2-3:  Option 2 代码 + 训练 + docs/09 main result
Week 4:    Ablations(A1-A5)
Week 5:    Paper draft
Week 6:    Submission
```

实际会延后(GPU 排队、调试、ablation 重跑),但**~6-8 周到 paper draft** 是合理估计。

## 7. Risks(必须 explicitly 记录)

### 7.1 Option 2 仍可能 fail

- **梯度仍冲突**:即使 teacher pre-aligned,L_DMD 和 L_MD 在 student 输出端的
  作用形式不一样(score gap vs noise prediction MSE),梯度方向可能仍偏。
- **如果 fail**:也是 paper material("aligned teacher does not resolve
  gradient conflict, suggesting deeper architectural change needed")。

### 7.2 Sequential(Option 1)可能足够好

- 如果 Option 1 amplitude 恢复 + 关 metric 不大 drop,Option 2 的 marginal
  gain 可能小,paper contribution 弱化。
- **mitigation**:扩大 motion data set,做 multi-category(UCF 10 类)的
  joint training,Option 2 的 generalization 优势可能浮现。

### 7.3 Teacher pretrain 的 motion data 量太小

- Phase 2 用 6 段 UCF Skateboarding clip。如果换成 10 类 60 段甚至 500 段
  (OpenVid motion subset),teacher pretrain 的成本上升 + 训练时长扩展。
- 当前不投这块,等 Option 2 跑通 + ablation 显示需要再说。

### 7.4 Few-step 推理性质破坏

- Option 1 / Option 2 都有可能让 student 偏离 few-step manifold,变成需要更多
  步才能 inference 出 ok 视频。
- **mitigation**:每个实验后必跑 "4-step inference quality" sanity test,
  跟 longlive_base 自身的 4-step 输出对比。

### 7.5 Compute budget overrun

- 估算的 ~150h GPU(全部 ablation)在 HPC 上不是免费 — 可能排队/中断。
- **mitigation**:Phase A(Option 1)成本低,先做完拿基线;Phase B 优先级
  排序,关键 config 先跑。

## 8. Scope(In / Out)

**In scope**:
- DMD 框架(Self-Forcing 的 Wan-14B / longlive_base)
- MotionDirector loss(L_temporal_MSE + L_AD)
- UCF / LOVEU 数据
- 5-metric eval(motion_eval + Dynamic Degree)

**Out of scope(本 paper 不做,future work)**:
- 整体换 distillation 算法(consistency / rCM / Causal Forcing) — paper 提
  及但不实施。理由:paper contribution 已经被 Option 2 框定,加换框架会
  scope creep。
- Wan-14B 之外的 base model
- 非 motion 的 customization 维度(style / subject)
- DMD step 内的"魔改"(violates `dmd_architecture_frozen`)— 这条 memory
  仍生效,Option 2 不是魔改,**而是在外面加 auxiliary loss**
